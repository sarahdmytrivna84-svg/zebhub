# ZebHub Website

A premium static technology-agency website built with:
- HTML5
- CSS3
- Vanilla JavaScript

## Files
- index.html
- style.css
- script.js

## Run
Open `index.html` directly in your browser, or use VS Code Live Server.

## Customize
- Replace `hello@zebhub.com` in `index.html` and `script.js` with your real business email.
- Edit project names and service copy in `index.html`.
- Change colors from the `:root` variables in `style.css`.
- No backend is required for the included demo contact form; it opens the user's email client.

## Features
- Responsive sticky navbar
- Animated mobile menu
- 3-slide hero carousel
- Arrow/dot navigation
- Touch swipe
- Auto-rotation
- Scroll reveal animations
- Parallax-style hero interaction
- Responsive service/project sections
- Accessible labels and reduced-motion support
- SEO-friendly title and meta description
